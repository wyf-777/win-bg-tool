# 需求说明

状态：与实现同步（2026-08-01：含 F14 更快处理）  
范围：Windows 本机图片去背景工具（可扩展设置与多图）。

## 1. 问题与目标

在 Windows 上提供可用的图片去背景能力：默认**本机**处理，可预览、可导出。  
质量与体验对齐 Peel 一类工具的日常强度，不复刻 Glaze/Mac 技术栈。  
**默认路径零硬件门槛**：用户无需了解 CPU/GPU。

## 2. 用户与场景

| 角色 | 场景 |
|------|------|
| 使用者 | 拖入/打开图 → 自动抠图 → 预览 → 导出/拖出 |
| 批量 | 多图网格、灯箱检查、选中或全部导出 |
| 进阶 | 设置中换模型、导出格式、主题、可选更快处理、快捷键 |
| 修正 | 修补页修蒙版；右键换已下载模型重抠单张 |

## 5. 技术约束（已定）

| 项 | 选择 |
|----|------|
| 语言 | Python 3.11+ |
| 本机引擎 | rembg + onnxruntime |
| 加速 | 可选 providers（CUDA / DirectML 等）；见 design-accel.md |
| UI | PySide6 |
| 默认模型 | isnet-general-use（可设置更换） |
| 模型缓存 | 项目 `models/`（U2NET_HOME） |
| 模型选用 | 全局当前模型；非内容自适应 |

## 6. 第一版验收（MVP）

以下均已满足，可视为 **MVP + 多图 + 设置增强 + 修补/剪贴板/F14 已交付**：

1. 断网可用本机模型抠图（模型已下载后）  
2. 打开与拖入可用  
3. 透明预览  
4. 可导出  
5. 异常有提示、主界面不假死  
6. 引擎与 UI 分层  
7. 默认普通模式可用；开启加速不导致无加速环境无法使用  

## 7. 风险

| 风险 | 应对 |
|------|------|
| CPU 慢 | 串行队列；F14 可选加速 |
| GPU 包/驱动复杂 | 默认 CPU 包；失败回退；不写进默认依赖 |
| 模型体积大 | 外置 models/；按需下载 |
| 难图边缘差 | 换模型；matting；修补；以后在线 |
| 模态文件框挡拖放 | 系统行为 |
