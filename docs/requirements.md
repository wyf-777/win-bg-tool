# 需求说明

状态：与实现同步（2026-07-27 进度审查）  
范围：Windows 本机图片去背景工具（可扩展设置与多图）。

## 1. 问题与目标

在 Windows 上提供可用的图片去背景能力：默认**本机**处理，可预览、可导出。  
质量与体验对齐 Peel 一类工具的日常强度，不复刻 Glaze/Mac 技术栈。

## 2. 用户与场景

| 角色 | 场景 |
|------|------|
| 使用者 | 拖入/打开图 → 自动抠图 → 预览 → 导出/拖出 |
| 批量 | 多图网格、灯箱检查、选中或全部导出 |
| 进阶 | 设置中换模型、导出格式、主题 |

## 7. 风险

| 风险 | 应对 |
|------|------|
| CPU 慢 | 串行队列；可选以后 GPU |
| 模型体积大 | 外置 models/；按需下载 |
| 难图边缘差 | 换模型；可选 matting；以后在线 |
| 模态文件框挡拖放 | 系统行为；关对话框即恢复 |
