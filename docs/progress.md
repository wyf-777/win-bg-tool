## 技术现状（简）

| 层 | 位置 | 说明 |
|----|------|------|
| 入口 | `app/main.py` / `run.bat` | `python -m app.main` |
| 引擎 | `engines/local_rembg.py` + `models_catalog.py` | rembg，可换模型 |
| 会话 | `session/batch_session.py` | 串行队列、上限 |
| 服务 | `services/settings.py` / `export.py` | 持久化设置、多格式导出 |
| UI | `main_window` / `workspace` / `settings_dialog` / `theme` | 主界面 + 全窗设置 |

默认模型：`isnet-general-use`；模型缓存：`models/`（U2NET_HOME）。

## 优化与注意点（非必须，建议知晓）

| 优先级 | 项 | 说明 |
|--------|----|------|
| 中 | 网格 resize 全量重建 | 窗口拖拽时可能卡；可防抖 |
| 中 | 主窗仍有部分私有 API 访问 workspace | 灯箱关闭等；可继续公有化 |
| 低 | 调试文件 | 仓库根 `_dbg_*.txt`、`models/tmp*` 宜清理/gitignore |
| 低 | 文档与代码小偏差 | 本次审查后已对齐 progress/requirements/README |
| 体验 | 模态「打开文件」挡拖放 | 属系统行为；用户取消专项改造 |
| 体验 | 首次用某模型需下载 | 正常；设置里已有说明 |
| 分发 | 未打包 | 给他人用需 PyInstaller 等 |
