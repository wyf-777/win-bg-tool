# F13 文件夹监视（热文件夹）设计说明

状态：**v1.2 已实现**  
最后更新：2026-08-01  
代码：`app/services/folder_watch.py`、设置页「文件夹」、`main_window`（托盘）

---

## 1. 产品默认

| 项 | 默认 |
|----|------|
| 输出 | `{监视}/已抠图`，可改 |
| 主界面会话 | 不进网格；后台导出 |
| 范围 | 仅开启后新文件；可选处理已有（确认） |
| 递归 | **默认关**；可开「包含子文件夹」 |
| 归档源文件 | **默认关**；可开则成功后移到 `{监视}/已处理` |
| 托盘 | **默认开**：监视中关窗口 → 最小化到托盘 |
| 清单 | 应用数据目录（用户导出夹内不可见） |

---

## 2. 用户路径

**设置 → 文件夹**

- 监视 / 输出路径  
- 开启时也处理已有  
- 包含子文件夹  
- 成功后归档到「已处理」  
- 关闭窗口最小化到托盘  
- 应用；暂停 / 清空队列 / **重试失败** / 打开输出 / 打开失败  

主界面底部：监视摘要。托盘：显示窗口 / 暂停继续 / 退出。

---

## 3. 能力一览

| 版本 | 能力 |
|------|------|
| v1 | 监视、默认已抠图、不入网格、仅新文件、稳定入队 |
| v1.1 | 清单（app data）、失败目录、暂停、清空、主界面状态 |
| **v1.2** | 递归、归档源文件、重试失败、关窗进托盘 |

---

## 4. 验收要点

1. 新图 → 已抠图；失败 → 失败/  
2. 递归：子目录图片写入输出相对路径  
3. 归档：成功后源在「已处理」，进图夹不再保留  
4. 重试失败：源仍在则重新排队  
5. 清单不在导出目录  
6. 监视开启 + 托盘：关窗不杀进程；托盘可退出  

---

## 5. 仍非目标
